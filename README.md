# 上海解除/终止补偿计算器

面向手机端的纯前端估算工具。无需登录、数据库或付费 API，不收集或上传用户输入。

## 本地运行

```bash
npm install
npm run dev
```

`npm run test`、`npm run lint`、`npm run build` 用于验证。构建产物位于 `dist/`，可部署到 CloudBase 静态托管或任何 HTTPS 静态托管平台。Vite 采用相对资源路径，适用于独立域名或子目录。

## 年度参数

在 `src/config/shanghai.ts` 更新上海月平均工资、三倍上限和月最低工资。当前 12,577 / 37,731 / 2,740 元为委托方暂设值，尚未作为最新官方标准确认。更新前请核对当期官方公告、适用时点与劳动合同履行地。

## 计算边界

- N 以解除/终止前最多12个月的月平均应得工资为基数；不满12个月可输入实际工资月数。
- N+1 中的“1”单独使用解除前一个月工资。
- 高工资适用暂设的三倍上限与12年年限上限；低于暂设最低工资时以最低工资托底。
- 2008年1月1日前入职者，只估算该日起的年限；2008年前可能应付的部分不自动计算，因此结果不是最终应付总额。
- “继续履行待判断”不显示零元；违法解除赔偿金 2N 不与 N 重复相加。
- 本工具不自动判断解除理由是否合法、劳动合同履行地、程序、其他补偿项目或个案争议。

## 部署

优先使用 CloudBase Web 应用独立子域名，后续更新同一应用以维持 URL。部署需腾讯云账号授权与明确的 EnvId。`dist/` 为公开静态内容，不能放密钥。GitHub 仓库仅提交源代码、锁文件和部署说明，不提交 `.env`、`node_modules` 或 `dist`。
